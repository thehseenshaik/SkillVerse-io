# SkillVerse — Your Complete Career Operating System

SkillVerse is an AI-powered Career OS that unifies LinkedIn, GitHub, LeetCode, resumes, courses and interviews into one dashboard.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
